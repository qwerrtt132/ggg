# ggg

## Algorithmic Trading — 30s TikTok explainer

A vertical (9:16) 30-second animated explainer of how algorithmic trading works.

- `video/algorithmic-trading.mp4` — the finished, TikTok-ready video (1080x1920, H.264)
- `video/scenes.html` — the animation source (open in any browser as a live preview)
- `video/render.js` — records `scenes.html` into the MP4 via Playwright + ffmpeg
- `video/SCRIPT.md` — voiceover script, captions, hashtags, and re-render steps
